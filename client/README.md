# Frontend Client Layer

Web-based UI for interacting with the interview preparation system.

## Structure

```
client/
├── public/         # Static HTML files
├── src/
│   ├── js/        # JavaScript files
│   ├── css/       # Stylesheets
│   └── assets/    # Images, fonts, etc.
└── dist/          # Built/bundled files
```

## Features

- Real-time streaming of agent outputs
- Interactive form for job details
- Beautiful, modern UI with animations
- Responsive design

## Setup

Currently using vanilla HTML/CSS/JS. No build step required.

## Usage

Open `public/index.html` in a browser, or serve via the backend:
- http://localhost:8000/web

See main project README for more details.
